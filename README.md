# Time tracking//work with data

My tenth Frontend Mentor project

## Preview

**Live Site:** (https://time-tracking-dashboard-main-sage-one.vercel.app/)

To view the project's source code, clone or download this repository. The main markup is in `index.html`, and the styles are in `style.css`.
Чтобы посмотреть исходный код проекта, клонируйте этот репозиторий или скачайте его архив. Основная разметка находится в файле index.html, стили — в style.css. 
Users can switch between daily, weekly, and monthly views. The displayed time for each category updates dynamically based on the selected period, using data from a JSON file.
Пользователи могут переключаться между дневным, недельным и месячным режимами просмотра. Отображаемое время для каждой категории динамически обновляется в зависимости от выбранного периода, используя данные из JSON-файла.
